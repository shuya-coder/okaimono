# 買い物リストWebアプリ

HTML、CSS、Vanilla JavaScriptだけで動く買い物アプリです。  
データはブラウザのLocalStorageに保存されるため、サーバーやデータベースは不要です。

スマートフォンで買い物中に片手操作しやすいように、商品追加、リスト確認、カート移動、会計済み処理をシンプルにまとめています。

## できること

- 商品を買い物リストへ追加
- 同じ商品を追加したときは個数を加算
- 商品をリストからカートへ移動
- カートの商品をリストへ戻す
- カート内の商品を会計済みにして履歴へ保存
- 履歴を日付ごとに確認
- 履歴を商品名、日付、カテゴリーで絞り込み
- カテゴリー名と色を自由に編集
- CSVでデータをエクスポート、インポート
- ダークモード切替
- LocalStorage初期化
- PWAとしてホーム画面へ追加
- オフライン利用

## すぐに起動する方法

1. `shopping-app` フォルダを開きます。
2. `index.html` をブラウザで開きます。
3. アプリが表示されれば利用できます。

ただし、PWAやService Workerの確認をする場合は、`file://` ではなくLive Serverなどの `http://localhost` から開いてください。

## VSCodeで開く方法

1. VSCodeを起動します。
2. `ファイル` から `フォルダーを開く` を選びます。
3. `shopping-app` フォルダを選択します。
4. 左側のファイル一覧から `index.html` を開きます。

## Live Serverで起動する方法

1. VSCodeで拡張機能を開きます。
2. `Live Server` を検索してインストールします。
3. `index.html` を右クリックします。
4. `Open with Live Server` を選びます。
5. ブラウザでアプリが開きます。

URL例:

```text
http://127.0.0.1:5500/index.html
```

## 別のパソコンへ移す方法

アプリ本体だけを移す場合:

1. `shopping-app` フォルダを丸ごとコピーします。
2. USBメモリ、クラウドストレージ、ZIPファイルなどで別PCへ移します。
3. 別PCで `shopping-app/index.html` を開きます。

データも一緒に移す場合:

1. 元のPCでアプリを開きます。
2. `⚙ 設定` タブを開きます。
3. `CSV保存` を押してデータを書き出します。
4. 別PCへ `shopping-app` フォルダとCSVファイルを移します。
5. 別PCでアプリを開きます。
6. `⚙ 設定` タブを開きます。
7. `CSV読込` から保存したCSVファイルを選びます。

LocalStorageはブラウザごと、端末ごとに保存されます。  
そのため、フォルダをコピーしただけでは買い物データは移りません。データ移行にはCSVエクスポート、CSVインポートを使ってください。

## スマートフォンで使う方法

PCからスマートフォンへ移す場合は、以下のどちらかを使います。

- スマートフォンで開ける場所に `shopping-app` を置く
- PCでLive Serverを起動し、同じWi-Fi内のスマートフォンからPCのURLへアクセスする

スマートフォンへホーム画面追加したい場合:

1. Live Serverなどで `http://localhost` またはHTTPS環境から開きます。
2. ブラウザのメニューを開きます。
3. `ホーム画面に追加` を選びます。
4. 追加されたアイコンから起動します。

Service Workerは `file://` では動きません。ホーム画面追加やオフライン利用を確認する場合は、Live ServerなどのHTTP環境で開いてください。

## 基本的な使い方

### 商品を追加する

1. `📝 リスト` タブを開きます。
2. `＋ 商品を追加` を押します。
3. 商品名、個数、カテゴリーを入力します。
4. `リストに追加` を押します。

商品追加後は、商品名だけ空になり、個数は1に戻ります。カテゴリーは前回選択したものが維持されます。続けて商品名を入力できます。

### リストの商品を操作する

商品カードには以下の操作があります。

```text
[カート] [＋] [－] [削除]
```

- `カート`: 商品をカートへ移動します
- `＋`: 個数を1つ増やします
- `－`: 個数を1つ減らします
- `削除`: 商品を削除します

削除時は確認ダイアログが表示されます。

### カートの商品を操作する

カートの商品カードには以下の操作があります。

```text
[戻す] [＋] [－] [削除]
```

- `戻す`: 商品をリストへ戻します
- `＋`: 個数を1つ増やします
- `－`: 個数を1つ減らします
- `削除`: カートから削除します

### 会計済みにする

1. `🛒 カート` タブを開きます。
2. 商品を確認します。
3. `会計済み` を押します。
4. 確認ダイアログでOKを押します。

会計済みにした商品はカートから消え、履歴へ保存されます。

### 履歴を見る

`📜 履歴` タブでは、会計済みにした商品を日付ごとに確認できます。  
商品名、カテゴリー、開始日、終了日で絞り込みできます。

### カテゴリーを編集する

`⚙ 設定` タブでカテゴリーを管理できます。

- カテゴリー追加
- カテゴリー名変更
- カテゴリー色変更
- カテゴリー削除

初期カテゴリーは以下の2つです。

- 食料品 `#4CAF50`
- 日用品 `#2196F3`

## データ保存について

データはLocalStorageに保存されます。保存キーは以下です。

- `shoppingApp:shoppingItems`
- `shoppingApp:categories`
- `shoppingApp:shoppingHistory`
- `shoppingApp:darkMode`

商品データは内部的に `status` でリストとカートを区別します。

```javascript
{
  id: 1,
  name: "牛乳",
  count: 2,
  categoryId: 1,
  status: "list", // "list" または "cart"
  checked: false,
  createdAt: "2026-07-02T10:00:00.000Z"
}
```

内部データでは `cart` という英語の値を使いますが、画面表示では「カート」に統一しています。

## CSVバックアップ

データを残したい場合は、定期的にCSV保存してください。

バックアップ手順:

1. `⚙ 設定` タブを開きます。
2. `CSV保存` を押します。
3. ダウンロードされたCSVファイルを保管します。

復元手順:

1. `⚙ 設定` タブを開きます。
2. `CSV読込` を押します。
3. 保存しておいたCSVファイルを選択します。

CSV読込を行うと、現在のLocalStorageデータはCSVの内容で置き換わります。必要な場合は先にCSV保存してください。

## よくあるトラブル

### データが別PCで表示されない

LocalStorageはPCやブラウザごとに別です。  
元のPCでCSV保存し、別PCでCSV読込してください。

### ホーム画面追加できない

`file://` で開いている場合、PWA機能は有効になりません。  
Live Serverなどで `http://localhost` から開いてください。

### オフラインで使えない

一度HTTP環境で開き、Service Workerが登録される必要があります。  
初回表示後にブラウザを再読み込みしてから確認してください。

### 画面が古いまま変わらない

ブラウザのキャッシュが残っている可能性があります。  
再読み込み、またはブラウザのキャッシュ削除を試してください。

### CSV読込に失敗する

このアプリからCSV保存したファイルを使ってください。  
表計算ソフトで列名や列数を変更すると、正しく読み込めない場合があります。

## 開発メモ

- フレームワークは使用していません。
- JavaScriptは機能ごとにファイル分割しています。
- グローバル変数は `window.ShoppingApp` 名前空間にまとめています。
- 外部APIやクラウド同期は使用していません。
- 今後、ログイン、共有、クラウド同期、通知、店舗別リストなどを追加しやすいよう、管理クラスを分けています。
