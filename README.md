# 買い物リストWebアプリ

HTML、CSS、Vanilla JavaScriptだけで動く、スマホ向けの買い物・レシート管理Webアプリです。
有料サービス、アプリサーバー、npm、Node.js、ビルド作業は不要です。

買い物データはLocalStorage、レシートの構造化データはIndexedDBに保存されます。レシートは、利用者がChatGPTで解析したJSONを貼り付けるか、手入力で登録します。アプリ自身は画像や購入情報を外部APIへ送信しません。全データの移行にはJSONバックアップを使用します。

## 別のパソコンへデータも移す方法

買い物リスト、カート、履歴、カテゴリーを移す場合はCSVを使います。

元PCで行うこと:

1. アプリを開きます。
2. `⚙ 設定` タブを開きます。
3. `CSV保存` を押します。
4. CSVファイルがダウンロードされます。
5. CSVファイルを新しいPCへ移します。

新PCで行うこと:

1. `shopping-app` フォルダを新PCへコピーします。
2. 新PCで `index.html` を開きます。
3. `⚙ 設定` タブを開きます。
4. `CSV読込` を押します。
5. 元PCで保存したCSVファイルを選びます。
6. リスト、カート、履歴、カテゴリーが復元されます。

LocalStorageはブラウザごと、PCごとに別管理です。
そのため、アプリ本体をコピーしただけでは買い物データは移りません。
データ移行には必ずCSV保存とCSV読込を使ってください。

買い物データを別PCへ移す場合は、OneDriveを使っている場合でもCSV保存とCSV読込が必要です。

## 基本的な使い方

### 商品を追加する

1. `📝 買い物` タブを開きます。
2. `＋ 商品を追加` を押します。
3. 商品名を入力します。
4. 個数を選びます。
5. カテゴリーを選びます。
6. `リストに追加` を押します。

商品追加後の動作:

- 商品名だけ空になります。
- 個数は `1` に戻ります。
- カテゴリーは前回選択したものが維持されます。
- 商品名入力欄にフォーカスが戻ります。
- 続けて次の商品を入力できます。

### リストの商品を操作する

商品カードには以下のボタンがあります。

```text
[購入] [編集] [＋] [－] [削除]
```

- `購入`: 商品をリストから除外し、日時・数量・カテゴリーを購入履歴へ記録します
- `編集`: 商品名・個数・カテゴリーを編集します
- `＋`: 個数を1つ増やします
- `－`: 個数を1つ減らします
- `削除`: 商品を削除します

削除時は確認ダイアログが表示されます。

### 履歴の商品を再追加する

`📜 購入履歴` タブでは、日付ごとの購入記録を確認し、各商品の `もう一度買う` で個数1として買い物リストへ追加できます。すでにリストにある商品は個数が1増えます。既存の累計商品データは「これまでに購入した商品」に残り、購入回数と最終購入日も維持されます。

絞り込める条件:

- 商品名
- カテゴリー

並び替え:

- 最終購入順
- あいうえお順
- 古いもの順
- 購入頻度が高い順

### レシートを登録する

1. `🧾 レシート` タブを開きます。
2. `ChatGPT用の解析指示をコピー` を押します。
3. ChatGPTへレシート写真とコピーした指示を送り、返されたJSONをコピーします。
4. アプリの入力欄へJSONを貼り付け、`JSONを読み込む` を押します。
5. 店舗名、日時、商品、数量、単価、金額、カテゴリー、割引、内税、外税、支払合計を確認します。
6. 不確かな項目は「要確認」のまま残るため、必要に応じて修正して保存します。

共通スキーマは `okaimono-receipt-v1` です。不明な値は `null`、不明なカテゴリーは「未分類」とします。不正なJSON、未対応のキー、範囲外の数値は実行せず拒否します。内税は合計へ加算せず、外税だけを一度扱って検算します。不一致は警告しますが保存できます。手入力登録も利用できます。支出集計には確認した支払合計を使用し、レシート記録は既存の購入履歴と別管理です。

レシート画面では、対象月の支出、日別・店舗別・カテゴリ別集計、商品別価格推移、値上がり・値下がり比較を確認できます。レシート履歴は日付別の折りたたみで表示され、開くと店舗名・合計金額・商品明細を確認できます。店舗名・商品名で検索し、過去の記録を編集・削除できます。

### カテゴリーを編集する

`⚙ 設定` タブでカテゴリーを管理できます。

できること:

- カテゴリー追加
- カテゴリー名変更
- カテゴリー色変更
- カテゴリー削除

初期カテゴリー:

- 食料品 `#4CAF50`
- 日用品 `#2196F3`
- 未分類 `#78909C`

## CSVバックアップ

データを残したい場合は、定期的にCSV保存してください。

CSVに含まれるデータ:

- 買い物リストの商品
- カテゴリー
- 累計購入商品
- 日付付き購入記録

バックアップ手順:

1. `⚙ 設定` タブを開きます。
2. `CSV保存` を押します。
3. ダウンロードされたCSVファイルを保管します。

復元手順:

1. `⚙ 設定` タブを開きます。
2. `CSV読込` を押します。
3. 保存しておいたCSVファイルを選択します。

注意:

- CSV読込を行うと、現在のLocalStorageデータはCSVの内容で置き換わります。
- 必要なデータが残っている場合は、先にCSV保存してください。
- 表計算ソフトでCSVの列名や列数を変更すると、正しく読み込めない場合があります。

## JSONバックアップ

`全データJSON` は、従来のLocalStorageデータに加え、IndexedDBのレシート記録と商品名・カテゴリ学習内容も保存します。

復元時には、買い物、購入履歴、カテゴリー、レシート、学習内容の件数を表示します。内容を確認してから `復元する` を押してください。復元すると同じ種類の現在データを置き換えるため、先に最新のJSONを保存することを推奨します。

## データ保存について

既存データは引き続きLocalStorageに保存されます。保存キーは以下です。

- `shoppingApp:shoppingItems`
- `shoppingApp:categories`
- `shoppingApp:purchasedItems`
- `shoppingApp:purchaseRecords`
- `shoppingApp:shoppingHistory`（旧版からの移行読込用）
- `shoppingApp:darkMode`

旧版で `status: "cart"` またはチェック済みだった商品は、初回読込時に買い物リストへ戻します。同名商品がリストにもある場合は数量を合算し、購入扱いにはしません。

```javascript
{
  id: 1,
  name: "牛乳",
  count: 2,
  categoryId: 1,
  status: "list",
  checked: false,
  createdAt: "2026-07-02T10:00:00.000Z"
}
```

購入操作ごとの記録は、累計商品データとは別に保存します。

```javascript
{
  id: "1761710000000-12345",
  sourceItemId: 1,
  name: "牛乳",
  count: 2,
  categoryId: 1,
  purchasedAt: "2026-10-29T10:00:00.000Z"
}
```

`sourceItemId` により同じ購入操作の重複記録を防止します。レシート記録はこのデータを更新しないため、購入回数を二重計上しません。

レシートはIndexedDB `shoppingAppReceipts` の `receipts` と `mappings` ストアに保存されます。画像やBlobは保存しません。

## よくあるトラブル

### index.htmlだけコピーしたらデザインが崩れる

`css`、`js`、`assets` が足りません。
`shopping-app` フォルダごとコピーしてください。

### データが別PCで表示されない

LocalStorageはPCやブラウザごとに別です。
元PCでCSV保存し、新PCでCSV読込してください。

### Chromeでは見えるがEdgeではデータがない

LocalStorageはブラウザごとに別です。
同じPCでもChromeとEdgeではデータが共有されません。
CSV保存とCSV読込で移してください。

### ホーム画面追加できない

`file://` で開いている場合、PWA機能は有効になりません。
Live Serverなどで `http://localhost` から開いてください。

### オフラインで使えない

一度HTTP環境で開き、Service Workerが登録される必要があります。
初回表示後にブラウザを再読み込みしてから確認してください。

アプリ本体を一度読み込めば、買い物・履歴・保存済みレシートの閲覧と編集はオフラインでも利用できます。ChatGPTでの写真解析には別途ネット接続が必要です。

### 画面が古いまま変わらない

ブラウザのキャッシュが残っている可能性があります。
再読み込み、またはブラウザのキャッシュ削除を試してください。

### CSV読込に失敗する

このアプリからCSV保存したファイルを使ってください。
表計算ソフトで列名や列数を変更すると、正しく読み込めない場合があります。

### 文字化けする

ファイルはUTF-8で保存してください。
VSCodeで開く場合は、右下の文字コードが `UTF-8` になっていることを確認してください。

## 開発メモ

- フレームワークは使用していません。
- JavaScriptは機能ごとにファイル分割しています。
- グローバル変数は `window.ShoppingApp` 名前空間にまとめています。
- 外部APIやクラウド同期は使用していません。
- Content Security Policyでスクリプトと通信先を同一オリジンに制限しています。
- Service Workerはバージョン付き資産を一括キャッシュし、旧版ファイルとの混在を防ぎます。

## 外部サービスについて

アプリは外部AI APIへ直接接続しません。ChatGPTへのレシート写真の送信と解析結果のコピーは、利用者がChatGPT上で行います。Tesseract.jsなどのOCRランタイムは同梱していません。

```text
http://127.0.0.1:5500/
```

自動回帰テスト:


確認済み項目:

- IndexedDBへのレシート保存・編集、集計、重複判定
- JSONバックアップ・復元
